Argus

Argus is a self-hosted recognition server that Shashin uses for face detection, face recognition, and object detection. It runs as a separate service and communicates with Shashin over HTTP.

Argus is optional. Without it, Shashin still scans, indexes, and serves your media — you just won't have face recognition or object detection.

What Argus Does

  • Face detection — finds faces in photos and videos, returns bounding boxes and crops.
  • Face recognition — compares detected faces against enrolled identities and suggests matches.
  • Object detection — identifies objects in photos (used when Ollama is not available) and returns class labels that become searchable keywords in Shashin.
  • Review queue — holds unconfirmed match suggestions for you to accept or reject.
  • Identity management — stores named identities, their enrolled face embeddings, and a gallery of associated detections.

Connecting Argus to Shashin

  1. Run Argus and note its URL (e.g. http://127.0.0.1:8000).
  2. Generate an API key in Argus.
  3. In Shashin, open Settings and enter the Argus server URL and API key under Face Recognition.
  4. Enable Face Detection and/or Object Detection as needed.
  5. Save — Shashin will verify the connection and show the Argus status.

How the Integration Works

Scanning

When a face or object scan runs in Shashin, each photo or video thumbnail is sent to Argus via its detect API. Argus returns detected faces (with identity suggestions if known) and/or object classes. Shashin stores these results as face tags (People) and keyword tags.

Tagging people

  1. Open any photo that shows a face clearly.
  2. Click the face crop in the detail panel to open the labeling UI.
  3. Type the person's name and confirm — this sends the face to Argus with a label, enrolling it as a training image for that identity.
  4. Repeat for a few more photos of the same person to improve recognition accuracy.
  5. Run a Face Scan from the Media Indexing tab.
  6. Open People, select a person, and check the Matches tab to confirm or reject suggestions from the Argus review queue.

Sync

Shashin and Argus stay in sync in two ways:

  • Sync with Argus button (People page) — pulls all identities, names, cover thumbnails, and enrolled status from Argus in one pass. Use this after first setup or after Shashin downtime.
  • Webhooks — Argus can push changes to Shashin in real time as they happen. See Webhooks for setup instructions.

Object detection fallback

If Ollama is configured and reachable, Shashin uses it for object detection instead of Argus. Argus is used as the fallback when Ollama is unavailable.
