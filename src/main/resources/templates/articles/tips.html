Tips & Tricks

Search

Search for keywords, file names, titles, descriptions, place names, by camera or lens, media types, media dimensions, or taken at dates

There are a few reserved search terms as well.

  • /search?term=shashinedit filters photos edited through the editor
  • /search?term=nolatlng filters media that don't have coordinates
  • /search?term=latlng filters media that have coordinates
  • /search?term=description filters media that have a description

Filters

For the timeline, explore pages, favorites and album pages, you can filter by media type or media with no coordinate data. In albums, you can also filter by media with comments.

  • Media types including, but not limited to:
    • video
    • image
    • gif
    • jpg
    • mp4
  • nolatlng filters media that don't have coordinates
  • description filters media that have descriptions
  • Albums only - comments filters media that have comments

Examples

  • /timeline/video
  • /taken/gif
  • /recent/nolatlng
  • /album/1/comments

Pagination

You can view recently added, modified, taken or accessed pages with pagination. Access by specifying the page index (starting from 0) and the media type.

You can jump to pages using the pagination navigation at the bottom of the page.

Examples

  • /recent/0/all goes to the first page and does not filter results
  • /taken/0/gif filters media by gifs and view the first page
  • /recent/1/nolatlng filters media that don't have coordinates and view the second page
  • /album/1/2/comments filters media that have comments and view the third page

Multi Select

You can multi select photos, which is useful if editing multiple photos.

  • Start by selecting a photo in multi select mode in the upper left corner of a photo
  • Hover over the last photo you want to select in a range of photos and press the shift to select the entire range of photos. The first photo in the range should have a blue outline.
    • Mobile: double tap the last photo you want to select in a range of photos.
  • You can deselect the photos by deselecting a photo within the range and press the shift to deselect the range of photos.
    • Mobile: double tap to deselect the range of photos.
