Quick Start

  1. For first time website setup, register your username and password on the registration page.
  2. Login as an administrator with the username and password you registered with.
    1. Subsequent registrations need to processed by an administrator on the User Management page.
  3. Once logged in as an administrator, go to the settings page from the sidebar.
  4. In the Settings tab in the Media directories and files text area, point to where your photos or videos are stored, separating directories with a new line. Example: 
    C:\Users\Michael\Pictures
C:\Users\Michael\Videos
  5. Click Save near the bottom of the page.
  6. In the Media Indexing tab, click the Scan button.
  7. After you see the message Scan Complete, view your media on the timeline page.

Face Recognition

You can use CompreFace using Docker Desktop as an alternative to the built-in face recognition module.

After setting up CompreFace, visit http://127.0.0.1:8000/ and click on Create Application. In the Application, click Create New.

Copy the API key and configure it in the Shashin settings under CompreFace API key. If CompreFace is hosted on the same network as Shashin, you should configure the CompreFace Endpoint to be a private or public IP.

Reset Password as an Admin

You need access to the shashin database.

Either reset the password with the shell script reset_shashin_password.sh and ensure you can execute it chmod +x reset_shashin_password.sh.

Usage ./reset_shashin_password.sh <username> to reset password in prod. To define an environment, type ./reset_shashin_password.sh <username> <prod/dev/test>

Output would be the new temporary password. You should change the password immediately afterward in Manage Account.

Or follow the steps:

  1. You need your username and an encrypted password.
  2. Visit http://127.0.0.1:6624/bcrypt to generate an encrypted password.
  3. UPDATE user SET password = "<encrypted password>"
    WHERE id = (SELECT id FROM user WHERE username = "<username>")
