Quick Start

  1. For first time website setup, register your username and password on the registration page.
  2. Login as an administrator with the username and password you registered with.
    1. Subsequent registrations need to processed by an administrator on the User Management page.
  3. Once logged in as an administrator, go to the settings page from the sidebar.
  4. In the Settings tab in the Media directories and files text area, point to where your photos or videos are stored, separating directories with a new line. Example: 
    C:\Users\Michael\Pictures
C:\Users\Michael\Videos
  5. Click Save near the bottom of the page.
  6. In the Media Indexing tab, click the Scan button.
  7. After you see the message Scan Complete, view your media on the timeline page.

Face Recognition

Shashin uses Argus for face recognition. Configure the Argus server URL and API key in Settings under Face Recognition.

Tagging people

  1. Open any photo in the gallery that shows a person's face clearly.
  2. Click the face crop in the photo detail panel to open the labeling UI.
  3. Type the person's name and confirm — this enrolls the face with Argus and creates a Training Image.
  4. Repeat for a few more photos of the same person to improve recognition accuracy.
  5. Run a Face Scan from the Media Indexing tab. Argus detects faces in all photos and queues candidates for review.
  6. Open People in the sidebar, select a person, and check the Matches tab to confirm or reject suggested identities.

Tip: enroll through Shashin so IDs are captured at the source. If a face does get enrolled directly in Argus, it is not broken — Shashin can re-sync by matching names via /api/identities/summary and re-pulling galleries via /api/identities/{id}/gallery to pick up the IDs it missed.
