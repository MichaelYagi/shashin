Argus Webhooks

Webhooks let Argus notify Shashin in real time whenever an identity or detection changes — renames, new people, merges, deletions, and face tag assignments all propagate immediately without waiting for a manual sync.

Webhooks are optional. If you do not configure one, the Sync with Argus button on the People page and the scheduled reconcile handle all synchronisation.

Setup

  1. In Argus, open Settings → Webhooks and add a new webhook.
  2. Set the URL to: 
    http://<your-shashin-host>:6624/api/argus/webhook
  3. Leave Secret blank.
  4. Subscribe to these events:
    • detection.labeled
    • identity.created
    • identity.deleted
    • identity.merged
    • identity.updated
  5. Save and use the Test button — Argus should report a 200 response.

What Each Event Does

Event What Shashin does
identity.created Creates a matching person in Shashin and links the Argus identity ID. If a person with the same name already exists and is not linked to another Argus identity, they are linked instead of duplicated.
identity.updated — renamed Updates the person's name in Shashin to match Argus.
identity.updated — thumbnail_updated Updates the person's cover thumbnail on the People page.
identity.updated — embedding_added Marks the corresponding face tag as manually confirmed (not auto-tagged).
identity.updated — embedding_removed Reverts the corresponding face tag back to auto-tagged.
identity.merged Moves all face tags from the deleted source person to the surviving target person, then removes the source.
identity.deleted Removes the person and all their face tags from Shashin.
detection.labeled Reassigns the face tag to the correct person when a detection is labeled or reassigned in Argus.

When to Use Sync With Argus

Even with webhooks active, run Sync with Argus (People page) after:

  • First connecting Argus — webhooks only deliver future events, not existing data.
  • Shashin downtime — any events fired while Shashin was offline are not replayed.
  • Changing which face model is active in Argus.
