Ollama

Ollama is a self-hosted service for running large language models locally. Shashin uses it with a vision-capable model to generate captions and keyword tags for your photos, and to power the Ask tab — a conversational Q&A interface on every photo.

Ollama is optional. If it is not configured or not reachable, Shashin falls back to Argus for object detection (if Argus is connected and object detection is enabled).

What Ollama Does in Shashin

  • Generates a warm, personal caption and keyword tags for each photo at scan time.
  • Tags and captions are stored in Shashin and become searchable alongside EXIF metadata.
  • Enables the Ask tab on every photo — ask any question about the photo and continue the conversation naturally.
  • Takes priority over Argus for object detection — if Ollama is reachable, Argus is not called for objects.
  • Photos that already have keyword tags from a previous scan are skipped unless a rescan is requested.

Connecting Ollama to Shashin

  1. Install and run Ollama.
  2. Pull a vision-capable model, for example: 
    ollama pull llava
  3. In Shashin, open Settings and enter the Ollama URL (e.g. http://127.0.0.1:11434) and the model name under Object Detection.
  4. Enable Object Detection.
  5. Save — Shashin checks whether the model is reachable before using it.

Running a Scan

Object detection runs as part of a media scan. Go to Media Indexing and click Scan. Shashin sends each photo to Ollama in turn and stores the returned tags. The scan skips photos that already have keyword tags unless you run a forced rescan.

After scanning, keyword tags are searchable from the search bar and visible in the photo detail panel.

Ask

When Ollama is connected with a vision model, an Ask tab appears in the photo detail modal. You can type any question about the photo and receive an answer from the model.

  • Conversations are contextual — you can ask follow-up questions and refer back to previous answers naturally (e.g. "What colour is the scarf?" → "What is it made of?").
  • Conversations are saved per photo — close the modal and reopen it later to continue where you left off.
  • The model is given the photo's date taken and location (place name and coordinates) as context, so it can answer questions like "When was this taken?" or "Where is this?".
  • Each turn sends only the current question and image — prior exchanges are encoded in Ollama's context token cache, keeping payloads small regardless of conversation length.

Argus Fallback

If Ollama is configured but unreachable at scan time, Shashin automatically falls back to Argus for object detection (provided Argus is connected and object detection is enabled). Photos that already have Ollama-generated tags are not re-processed by Argus.
