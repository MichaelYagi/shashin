Ollama

Ollama is a self-hosted service for running large language models locally. Shashin integrates with Ollama for three things: generating captions and keyword tags for your photos, powering the Ask tab for conversational Q&A on any photo, and enabling semantic search across your entire library.

Ollama is optional. If it is not configured or not reachable, Shashin falls back to Argus for object detection (if Argus is connected and object detection is enabled).

What Ollama Does in Shashin

  • Generates a caption and keyword tags for each photo at scan time.
  • Tags and captions are stored in Shashin and become searchable alongside EXIF metadata.
  • Enables the Ask tab on every photo — ask any question about the photo and continue the conversation naturally.
  • Powers semantic search — find photos by meaning using the nomic-embed-text embedding model.
  • Takes priority over Argus for object detection — if Ollama is reachable, Argus is not called for objects.
  • Photos that already have keyword tags from a previous scan are skipped unless a rescan is requested.

Connecting Ollama to Shashin

  1. Install and run Ollama.
  2. Pull a vision-capable model, for example: 
    ollama pull qwen3-vl:8b-instruct
  3. In Shashin, open Settings, enter the Ollama URL (e.g. http://127.0.0.1:11434), and click Load models to select your vision model.
  4. Save settings.

Running a Scan

Caption and keyword generation runs as part of a media scan. Go to Media Indexing and click Scan. Shashin sends each photo to Ollama in turn and stores the returned caption and tags. The scan skips photos that already have keyword tags unless you run a forced rescan.

After scanning, keyword tags and captions are searchable from the search bar and visible in the photo detail panel.

Ask

When Ollama is connected with a vision model, an Ask tab appears in the photo detail modal. Type any question about the photo and receive an answer from the model.

  • Conversations are contextual — ask follow-up questions and refer back to previous answers naturally (e.g. "What colour is the scarf?" → "What is it made of?").
  • Conversations are saved per photo — close the modal and reopen it later to continue where you left off.
  • The model is given the photo's date taken and location (place name and coordinates) as context, so it can answer questions like "When was this taken?" or "Where is this?".
  • Each turn sends only the current question and image — prior exchanges are encoded in Ollama's context token cache, keeping payloads small regardless of conversation length.

Semantic Search

Semantic search lets you find photos by meaning rather than exact keywords — search for "birthday cake" and find photos captioned "celebrating with candles", or search for "dogs on the beach" and surface relevant shots even if those words never appear in any tag.

It uses nomic-embed-text, a lightweight embedding model that runs locally via Ollama alongside your vision model.

Setup

  1. Pull the embedding model: 
    ollama pull nomic-embed-text
  2. Open Settings. Once the Ollama URL is configured and nomic-embed-text is detected, a Generate embeddings button appears — click it to embed all photos that have captions.
  3. Progress is shown in real time. The job runs on the server, so you can navigate away and return to check progress.

Using Semantic Search

Once embeddings are generated, the regular search bar automatically blends results. Keyword matches always appear first (exact matches rank highest), followed by semantically similar photos that may not share any of the same words. There is no mode to switch — it just works.

Semantic search is also available as a standalone REST API endpoint:

GET /api/v1/search/semantic?q=dogs+on+the+beach&size=20
x-api-key: <your-api-key>

New photos scanned after embeddings are generated will have their embeddings created automatically at scan time, so the index stays up to date without manual intervention.

Argus Fallback

If Ollama is configured but unreachable at scan time, Shashin automatically falls back to Argus for object detection (provided Argus is connected and object detection is enabled). Photos that already have Ollama-generated tags are not re-processed by Argus.
