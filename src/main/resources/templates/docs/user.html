User

User management

Roles: Admin, User

POST /api/v1/users/login

Login with optional remember me. You must persist and use the sessionid response value returned in subsequent requests.

Request

var type values required
username string ✓
password string ✓
remember-me string on

/api/v1/users/login
{"username":"auser","password":"apassword","remember-me":"on"}

Response

var type values description
msg string
status string success/fail
id int User ID
username string
sessionid string
authority string ROLE_ADMIN/ROLE_USER

{"msg":"Logged in!","status":"success","id":1,"username":"auser","sessionid": "ABC123","authority":"ROLE_ADMIN"}
