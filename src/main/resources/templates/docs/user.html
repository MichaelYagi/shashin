User

User management

Roles: Any

POST /api/v1/users/login

Login with optional remember me. You must persist and use the JSESSIONID cookie value returned.

var type values required
username string ✓
password string ✓
remember-me string on

Request

/api/v1/users/login
{"username":"auser","password":"apassword","remember-me":"on"}

Response

{"msg":"Logged in!","status":"success","id":1,"username":"auser","sessionid": "ABC123","authority":"ROLE_ADMIN"}

GET /api/v1/users/logout

Log user out.

Request

/api/v1/users/logout

Response

{"msg":"Logged out!","status":"success"}
