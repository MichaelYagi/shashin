Metadata

Image or video Metadata.

Roles: Admin

GET /api/v1/update/metadata/{metadataId}

Update image or video metadata.

Request

var type values description required
metadataId string UUID Query parameter ✓
id string UUID Metadata ID must match query parameter ✓
title string Metadata title. ✓
year int Metadata taken year. ✓
month int Metadata taken month. ✓
day int Metadata taken day. ✓
time string hh:mm:ss Metadata taken time. ✓
offset string Metadata offset time. ✓
latlng string lat, lng Metadata comma seperated latitude and longitude. ✓
keywords string Metadata comma seperated keywords. ✓
tagpeople string Metadata comma seperated strings of tagged people. ✓
isObject boolean true/false Metadata is object flag. ✓
hidden boolean true/false Metadata hidden flag. ✓

/api/v1/update/metadata/a9c80e5a-df23-3eb3-946d-a32b642f360e
{"id":"a9c80e5a-df23-3eb3-946d-a32b642f360e","title":"atitle","year":"2021","month":"12","day":"10","time":"10:54:03","offset":"","latlng":"16.767027233104788, -3.002658064842075","keywords":"asdf","tagpeople":"Noah,Ryuko","albumnames":"asdf","hidden":false,"isObject":false}

Response

var type values description
msg string
status string success/fail

{"msg": "Saved!","status": "success"}

GET /api/v1/update/metadata/batch

Batch update image or video metadata.

Request

var type values description required
batchMetadataIds string Array of metadata ID's ✓
yearTakenBatchData int Metadata taken year.
monthTakenBatchData int Metadata taken month.
dayTakenBatchData int Metadata taken day.
latlngBatchData string lat, lng Metadata comma seperated latitude and longitude.
keywordsBatchData string Metadata comma seperated keywords.
albumNameInput string Albums these images or videos belong to.
tagBatchDataInput string Metadata comma seperated strings of tagged people.
batchisobject string on Metadata is object flag.
batchhidden string on Metadata is object flag.
